# Теннис Класс — SVAO

Одностраничный сайт школы тенниса «Теннис Класс» (Москва, ул. Верхоянская, 9 · м. Свиблово).

## Структура
- `index.html` — исходник сайта, изображения в `img/`.
- `build.py` — сборка в один HTML-файл со встроенными (base64) картинками:
  ```bash
  python3 build.py output.html
  ```

## Хостинг
GitHub Pages: ветка `main`, корень репозитория. `index.html` отдаётся как есть.
